# Course Registration System - Haskell Implementation

**Group Members:** Devesh Parekh and Rommel Gouala  
**Programming Language:** Haskell (GHC version 9.4+)  
**Required Libraries:** standard base library only

## Compilation and Execution
To compile and run the program, ensure GHC is installed and run the following commands in the terminal:
`ghc src/Main.hs -o registration_system`
`./registration_system`
